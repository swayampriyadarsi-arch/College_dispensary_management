# College Dispensary Management System

A full-stack web application developed to streamline and digitize college dispensary operations. The system helps manage patient records, medicine inventory, healthcare facilities, and dispensary services through an intuitive and responsive interface.

## Features

* Patient record management
* Medicine inventory tracking
* Healthcare facility information management
* Search and filtering functionality
* CRUD operations for efficient data handling
* Responsive user interface
* REST API integration
* Secure data storage and retrieval

## Tech Stack

### Frontend

* React.js
* HTML
* CSS
* JavaScript
* Axios

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## Installation

### Clone the Repository

```bash
git clone https://github.com/swayampriyadarsiwach/College_dispensary_management.git
cd College_dispensary_management
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Frontend Setup

```bash
cd frontendDispensary
npm install
npm run dev
```

## Usage

1. Start the backend server.
2. Start the React frontend.
3. Open the application in your browser.
4. Manage patients, medicines, facilities, and dispensary records through the dashboard.
